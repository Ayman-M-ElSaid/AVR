HD44780 LCD Driver

A lightweight, struct-based HD44780 driver for AVR microcontrollers. Full port configuration resolved at runtime — no hardcoded registers in application code.

4-bit mode
ATmega32
AVR-GCC

Demo

Simulated in Proteus on an ATmega32. Scrolls "Eid Mubarak!" across both rows of a 16×2 LCD.

Features
⚡
4-bit interface
Only 4 data lines required — saves GPIO pins on your MCU.
🧩
Single-call init
Pass a port name char 'A'–'D' — the driver resolves all register pointers automatically.
📐
Struct-based HAL
All port and pin state lives in the LCD struct. No globals, no macros.
🎯
Cursor control
Position the cursor anywhere via lcd_goto(row, col).
Pin Mapping

The driver assumes a full AVR port is dedicated to the LCD:

Port PinLCD SignalNotes
Pin 2E — EnableLatches data on falling edge
Pin 3RS — Register SelectLow = command, High = data
Pin 4–7D4–D7 — Data busUpper nibble first, then lower
Pin 0–1—Unused; driven as outputs (DDR = 0xFF)
API
// Initialize the LCD on a given AVR port ('A', 'B', 'C', or 'D')
void lcd_init_4bit(LCD *lcd, char port_name);

// Send a raw command byte
void lcd_command(LCD *lcd, unsigned char cmd);

// Send a single data character
void lcd_data(LCD *lcd, unsigned char data);

// Clear the display (includes 2ms settle delay)
void lcd_clear(LCD *lcd);

// Print a null-terminated string at the current cursor position
void lcd_print(LCD *lcd, char *string);

// Move cursor to row (0–1) and column (0–15)
void lcd_goto(LCD *lcd, uint8_t row, uint8_t col);
Usage Example
#include "lcd.h"

int main(void)
{
    LCD lcd;
    lcd_init_4bit(&lcd, 'A');   // Use PORTA

    lcd_goto(&lcd, 0, 0);
    lcd_print(&lcd, "Hello,");
    lcd_goto(&lcd, 1, 0);
    lcd_print(&lcd, "World!");

    while (1);
    return 0;
}
Initialization Sequence

Standard HD44780 4-bit startup sequence sent by lcd_init_4bit():

0x33 → 0x32Force 4-bit mode
0x282-line display, 5×8 font
0x08Display off
0x01Clear display
0x06Entry mode — increment cursor, no shift
0x0CDisplay on, cursor off, blink off
